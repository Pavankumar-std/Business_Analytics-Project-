# Netflix Business Analytics — Auspify Internship

## Project Overview

This project analyzes a Netflix titles dataset as part of the Auspify Technologies Business Analytics Internship. The project focuses on content distribution, country-wise content availability, audience ratings, and content growth trends.

## Tasks Completed

### Task 1: Netflix Content Portfolio Analysis
- Analyzed the distribution of Movies and TV Shows.
- Movies: 6,126 titles (69.69%).
- TV Shows: 2,664 titles (30.31%).
- Created charts to visualize the content distribution.

### Task 2: Global Market Performance Analysis
- Analyzed country-wise content distribution.
- United States: 3,240 titles.
- India: 1,057 titles.
- United Kingdom: 638 titles.
- Created a chart showing the top 10 countries by title count.

### Task 3: Audience Segmentation Analysis
- Analyzed content ratings.
- Compared ratings between Movies and TV Shows.
- Identified TV-MA as the most common rating for both content types in the comparison chart.
- Created visualizations to compare content ratings.

### Task 4: Content Growth and Trend Analysis
- Analyzed content release years.
- Examined catalogue additions by year.
- Found that catalogue additions peaked in 2019, with 2,016 titles in the supplied dataset.
- Created trend charts for release years and catalogue additions.

## Dataset Information

- **Dataset:** `Dataset.csv`
- **Total Records:** 8,790
- **Total Columns:** 10

The dataset includes show ID, content type, title, director, country, date added, release year, rating, duration, and listed category.

## How to Run the Project

1. Download or clone this repository.
2. Open `Auspify_Business_Analytics.ipynb` in Google Colab or Jupyter Notebook.
3. Upload `Dataset.csv` to the notebook environment.
4. Run the code cells in order.
5. Review the generated tables, charts, and business insights.

## Key Business Insights

- Movies represent the largest share of the supplied Netflix dataset.
- The United States has the highest country-associated title count, followed by India.
- TV-MA is the most common content rating for both Movies and TV Shows in the comparison chart.
- Catalogue additions increased substantially from 2015 and peaked in 2019 in the supplied dataset.

## Limitations

- Country counts may overlap because some titles are associated with multiple countries.
- Content ratings describe classifications, not actual viewer demographics.
- The dataset does not include revenue, viewing hours, or customer engagement metrics.
- Findings represent the supplied dataset and should not be treated as a complete measure of Netflix's current business performance.

## Tasks covered
1. Netflix Content Portfolio Analysis
2. Global Market Performance Analysis
3. Audience Segmentation Analysis
4. Content Growth & Trend Analysis

## Tools
Python, Pandas, Matplotlib, Google Colab/Jupyter.

## Dataset
Place `Dataset.csv` beside the notebook. The supplied dataset has 8,790 rows and 10 columns.

## Key findings
- Movies: 6,126 (69.69%); TV Shows: 2,664 (30.31%).
- Highest country-associated title count: United States (3,240), followed by India (1,057).
- TV-MA is the most common rating for both content types in the comparison chart.
- Catalogue additions peak in 2019 in this dataset: 2,016 titles.

## Run
Open the notebook in Google Colab or Jupyter, upload `Dataset.csv`, and run cells from top to bottom.

## Notes
Country counts overlap when titles list multiple countries. Ratings classify content and do not prove viewer demographics. The dataset has no revenue or viewing-engagement metrics.
